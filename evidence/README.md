# Evidence

Evidence records what happened; it does not define what should happen.

Accepted receipts are immutable, content-addressed where practical, and retain
the source revision, command or entry point, input and output digests, result,
and external trace references needed to reproduce or inspect the claim. Secrets
and raw provider credentials never belong here.

Product acceptance evidence and AES admission evidence are separate lineages.
Policy output must not rewrite the product baseline it evaluates.
